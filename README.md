# Dynamic Island — Xcode project skeleton

Open `DynamicIsland.xcodeproj` in Xcode.

This is a buildable starter project with placeholder implementations for the project files
that were not provided in the conversation. Replace the placeholder Swift files with your
existing implementations before expecting the full Dynamic Island functionality.

Before signing:
- Set your own Team in Signing & Capabilities.
- Replace `com.example.DynamicIsland` with a unique Bundle Identifier.
- Enable WeatherKit for your App ID and provisioning profile if you use WeatherKit.
- Review App Sandbox compatibility for any helper tools or AppleScript usage.

The project targets macOS 13.0 or later.
